# Independent numeric checks

The CSV in this folder records values independently checked from the supplied final dataset after excluding the 25 documented post-exit records. The Stata code should reproduce these values up to rounding and software-specific finite-sample details.

Stata was not installed in the environment used to assemble this package. The TeX fragments in `output/tables` are verification snapshots. Running `00_master.do` overwrites them with Stata-generated versions.
